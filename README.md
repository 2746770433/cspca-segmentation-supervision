# Segmentation-supervised multitask MRI classification of csPCa

This repository accompanies a manuscript prepared for submission to 《计算机应用研究》. The source code is provided in [`cspca_code_only.zip`](cspca_code_only.zip). Download and extract the archive to access the preprocessing, training, and evaluation scripts, configuration templates, dependency list, and usage instructions.

The public-release archive contains no MRI images, lesion masks, patient-level predictions, patient split tables, training logs, or model weights. The original PI-CAI data must be obtained from the official source under its terms. Without the original study splits and model weights, this archive alone cannot reproduce historical checkpoint inference. See the archive's `README.md` and `THIRD_PARTY_DATA.md` for details.

The corresponding author is Zhong Jin, Hefei Normal University. Bibliographic details will be added after publication.
